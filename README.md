## Introducción
Este repositorio contiene el desarrollo integral de un robot autónomo sube-escaleras desarrollado para la asignatura de **Mecatrónica** (Grado en Ingeniería de Robótica Software, URJC). El proyecto abarca el diseño y fabricación mecánica original, la arquitectura electrónica, los sistemas de sensado para la evasión de obstáculos y el control embebido para la superación de peldaños sin tracción por ruedas convencionales.

Para consultar todos los requisitos, restricciones técnicas, entregables y criterios de evaluación al detalle, puedes revisar el [enunciado completo del proyecto](doc/0_enunciado.pdf).
